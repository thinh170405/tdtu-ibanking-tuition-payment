# Phân hệ đóng học phí iBanking

Ứng dụng mô phỏng thanh toán học phí với giao diện React, ba backend FastAPI và PostgreSQL. Người dùng đăng nhập, tra cứu học phí theo MSSV, thanh toán toàn bộ khoản học phí và xác nhận bằng OTP qua email.

## Bắt đầu

Xem [hướng dẫn cài đặt và chạy](src/README.md). Sau khi chạy Docker Compose, mở giao diện tại <http://localhost:5173>, hộp thư demo tại <http://localhost:8025> và pgAdmin tại <http://localhost:5050>.
